# Subscription Manager - 專案規格文檔

## 專案概述

Subscription Manager 是一個現代化的訂閱管理 Web 應用程式，讓用戶能夠輕鬆追蹤和管理各種訂閱服務。應用程式提供直觀的介面來添加、編輯、查看和分析訂閱資訊。

## 主要功能

- **訂閱管理**：添加、編輯、刪除訂閱項目
- **品牌自動填寫**：整合 Brandfetch API 自動獲取品牌圖標
- **統計分析**：顯示訂閱總費用和趨勢
- **響應式設計**：支援桌面和移動設備

## 資料庫架構

### Subscriptions 表格

```sql
CREATE TABLE public.subscriptions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  brand TEXT NOT NULL,
  price DECIMAL(10,2) NOT NULL,
  currency TEXT DEFAULT 'TWD',
  start_date DATE NOT NULL,
  end_date DATE NOT NULL,
  cycle TEXT NOT NULL CHECK (
    cycle IN ('30days', '6months', '1year')
    OR cycle LIKE 'custom:days:%'
    OR cycle LIKE 'custom:months:%'
    OR cycle LIKE 'custom:years:%'
  ),
  icon_url TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Row Level Security (RLS)

- 已啟用 RLS 政策，只允許已認證用戶訪問

## API 端點

### Supabase Edge Functions

- `POST /functions/v1/brandfetch-api`：獲取品牌圖標

### 前端服務

- `supabaseService.ts`：Supabase 資料庫操作
- `brandfetchService.ts`：品牌圖標獲取
- `subscriptionService.ts`：訂閱 CRUD 操作

## 開發環境設置

### 環境變數

```bash
# 前端環境變數 (frontend/.env)
REACT_APP_SUPABASE_URL=your_supabase_url
REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key

# Supabase Edge Function 環境變數
BRANDFETCH_API_KEY=your_brandfetch_api_key
```

### 開發命令

```bash
# 前端開發
cd frontend && npm start

# 建置生產版本
cd frontend && npm run build

# 部署
cd frontend && npx vercel --prod

# Supabase 本地開發
npx supabase start

# 推送資料庫遷移
npx supabase db push

# 部署 Edge Functions
npx supabase functions deploy
```
